# Мастер подготовки Render для нового userbot

## Цель

Добавить одну локальную команду `tg-migrator prepare-render`, которая создаёт
отдельную Telegram StringSession для нового аккаунта и копирует готовый блок
переменных Render в буфер обмена. Существующая файловая сессия Desiree, её
Keychain-настройки и основная логика публикации не изменяются.

## Поток

1. Команда загружает существующие `TG_API_ID` и `TG_API_HASH` из окружения или
   macOS Keychain.
2. Новый телефон вводится скрыто и используется только в памяти процесса.
3. Telethon создаёт новую `StringSession`; код Telegram и пароль 2FA вводятся
   скрыто в терминале.
4. Новые `DATABASE_URL` и `MAX_BOT_TOKEN` вводятся скрыто. Утёкшая ранее строка
   Neon не используется: перед запуском владелец сбрасывает пароль базы.
5. Команда формирует полный env-блок с безопасными настройками проекта и
   `TG_AUTOMATION_ENABLED=false`.
6. На macOS блок передаётся напрямую в `pbcopy`. Секреты не печатаются, не
   записываются на диск и не попадают в Git.
7. Пользователь вставляет блок в Render через `Add from .env`. Новый режим
   включается только после проверки аккаунта, базы, `@webnmy` и MAX.

## Состав env-блока

Обязательные секреты: `TG_API_ID`, `TG_API_HASH`, `TG_PHONE`,
`TG_SESSION_STRING`, `DATABASE_URL`, `MAX_BOT_TOKEN`.

Фиксированные настройки: владелец `8235497168`, назначение `webnmy`, первый
источник `animeworldmem`, MAX-канал `channel_animenaruto`, подпись `НАШ ТГК`
со ссылкой `https://t.me/webm4ik`, параметры очереди и health-порт.

## Ошибки и безопасность

- Команда прекращает работу до копирования, если любой обязательный секрет
  пуст, Telegram-вход не завершён или `pbcopy` недоступен.
- В сообщениях об ошибках и тестах значения секретов не отображаются.
- Готовый блок не возвращается из функции копирования и не логируется.
- Авторизованная новая сессия живёт только в памяти до помещения env-блока в
  системный буфер обмена.

## Проверка

Модульные тесты проверяют полный набор ключей, безопасный выключенный флаг,
экранирование значений для dotenv и передачу блока в clipboard без вывода
секретов. Полный существующий набор тестов должен остаться зелёным.
